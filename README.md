欢迎来到 **Xiexie VPN** 的官方公告与社区讨论中心！

本仓库主要用于发布项目全局性通知，包括但不限于：
- 🚀 **前后端架构升级与接口变更**
- 📱 **各端客户端（Windows / Android / Linux ）版本发布与更新日志**

## 💬 如何参与讨论？

所有的公告与讨论均集中在 **[Discussions（讨论区）](https://github.com/xiexievpn/announcements/discussions)**：

1. **[📢 查看官方公告 (Announcements)](https://github.com/xiexievpn/announcements/discussions/categories/announcements)**
   - 仅官方维护者有权限发布主题帖，保证公告不被淹没。
   - **所有 GitHub 用户均可在每条公告下方跟帖、留言、提出问题与建议**。
2. **[💡 功能建议与反馈 (Ideas)](https://github.com/xiexievpn/announcements/discussions/categories/ideas)**
   - 欢迎社区用户自由发帖，提出你对 Xiexie VPN 的优化想法。
3. **[💬 综合交流 (General)](https://github.com/xiexievpn/announcements/discussions/categories/general)**
   - 自由探讨与日常使用交流。
